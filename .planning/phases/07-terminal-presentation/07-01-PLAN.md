<threat_model>
Threats:
- T-07-01: Terminal escape sequence corruption & unrecovered cursor state on crashes/signals. If an uncaught exception, SIGINT, or SIGTERM interrupts the process while the alternate screen is active and cursor is hidden, the developer's terminal remains corrupted or invisible.
- T-07-02: Malicious diff ANSI injection & unescaped control characters in source code snippets. Untrusted repository source code containing embedded ANSI escape codes or control characters (`\x1b[2J`, `\r`, `\x07`) could manipulate the terminal display or spoof status badges.
- T-07-05: CI pipeline hang on unhandled interactive TUI prompt. If the TUI launches inside an automated CI runner (e.g. GitHub Actions) or non-TTY piped output, the process could block waiting on stdin input indefinitely.

Mitigations:
- T-07-01 Mitigation: `TerminalLifecycleManager` hooks `process.once('exit')`, `SIGINT`, `SIGTERM`, and `uncaughtException`. It unconditionally writes `\x1b[?1049l\x1b[?25h` directly and synchronously to the output stream, guaranteeing original scrollback and visible cursor restoration.
- T-07-02 Mitigation: Syntax highlighting sanitizes control characters before formatting, and line gutter formatting strictly calculates line widths and prefixes via numeric bounds. Untrusted source text never controls ANSI styling logic.
- T-07-05 Mitigation: `shouldUseTui` strictly validates `process.stdout.isTTY`, checks `process.env.CI`, verifies `TERM !== 'dumb'`, and checks for `--no-tui`, `--plain`, `--json`, `--sarif`, `--quiet`, or `--output`. Any falsy condition immediately forces non-interactive mode.
</threat_model>

    1. Create `src/renderers/tui/syntax.ts`:
       - Implement lightweight regex token coloring using `picocolors`:
         - Match keywords: `const`, `let`, `var`, `function`, `return`, `if`, `else`, `for`, `while`, `import`, `export`, `from`, `class`, `interface`, `type`, `async`, `await`, etc. (color: `pc.blue(pc.bold(m))`)
         - Match strings: double quotes, single quotes, backticks (color: `pc.green(m)`)
         - Match comments: `// ...` and `/* ... */` (color: `pc.dim(pc.italic(m))`)
         - Match numbers: numeric literals (color: `pc.yellow(m)`)
       - Function `highlightTokens(code: string): string`:
         - Strips unsafe control characters (`/[\x00-\x08\x0B\x0C\x0E-\x1F\x7F]/g`) to prevent ANSI injection (T-07-02).
         - Applies token highlighting regex replacements.
       - Interface `CodeSnippetOptions`:
         - `lines: string[]`
         - `startLine: number` (1-indexed)
         - `highlightStart: number`
         - `highlightEnd: number`
         - `contextRadius?: number | undefined` (default 4 per D-05)
       - Function `formatCodeSnippet(options: CodeSnippetOptions): string[]`:
         - Slices context window `[highlightStart - contextRadius, highlightEnd + contextRadius]`.
         - Calculates gutter width dynamically from `maxLineNum`.
         - For target lines: formats line number in `pc.red`, pointer `pc.bold(pc.red('>'))`, and highlighted content.
         - For context lines: formats line number in `pc.dim`, separator `pc.dim('│')`, and highlighted content.
         - Returns formatted lines array.
       - Function `formatDiffLines(diffText: string): string[]`:
         - Colorizes git diff hunk lines: additions `+` in `pc.green`, deletions `-` in `pc.red`, hunk header `@@` in `pc.cyan`, context in `pc.dim`.

    2. Create `src/renderers/tui/diff.ts`:
       - Function `extractFileDiffHunk(diffText: string, filePath: string): string`:
         - Parses unified diff text (e.g. from git diff).
         - Locates the diff section corresponding to `filePath` (`diff --git a/... b/...` or `--- a/... +++ b/...`).
         - Extracts only the hunk headers and diff lines for that specific file.
         - If no diff hunk is found for `filePath`, returns empty string.

    3. Create `src/renderers/tui/clipboard.ts`:
       - Function `copyViaOsc52(text: string, stream?: NodeJS.WriteStream | undefined): boolean`:
         - Encodes text to base64.
         - Emits OSC 52 sequence: `\x1b]52;c;${base64}\x07`.
         - Returns `true` if write succeeded, `false` on catch.
       - Function `copyViaOsCommand(text: string): Promise<boolean>`:
         - Detects platform (`darwin` -> `pbcopy`, `win32` -> `clip.exe`, `linux` -> `wl-copy` if `WAYLAND_DISPLAY`, else `xclip -selection clipboard`).
         - Spawns subprocess with pipe stdio and timeout.
         - Writes text and resolves `true` on code 0, `false` on error.
       - Function `copyToClipboard(text: string): Promise<boolean>`:
         - Tries `copyViaOsc52(text)` first.
         - Falls back to `copyViaOsCommand(text)`.
       - Function `formatPatchPreview(finding: RankedFinding): string`:
         - Produces valid unified diff header:
           ```
           --- a/${file}
           +++ b/${file}
           @@ -${start},1 +${start},1 @@
           +${fix}
           ```
