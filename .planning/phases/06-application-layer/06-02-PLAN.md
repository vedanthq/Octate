<threat_model>
Threats:
- T-06-03: Path traversal / file clobbering: `--output <file>` option accepting malicious paths or failing when parent directories do not exist, causing data loss or abrupt process crashes.
- T-06-04: Schema corruption / malformed SARIF: SARIF output that violates the OASIS SARIF v2.1.0 standard, causing GitHub Code Scanning or CI security scanners to reject uploaded findings.
Mitigations:
- T-06-03 Mitigation: `writeRenderedOutput` parses target paths, creates any missing parent directories recursively via `mkdir(dirname(outputFile), { recursive: true })`, writes UTF-8 encoded text atomically via `writeFile`, and routes confirmation messages exclusively to `stderr` (`Wrote results to <file>\n`) so stdout streams remain untouched.
- T-06-04 Mitigation: `SarifRenderer` uses the proven `node-sarif-builder` builder DSL to construct compliant SARIF v2.1.0 runs, drivers, rules, and physical locations, mapping severities deterministically (`critical`/`high` → `error`, `medium` → `warning`, `low`/`info` → `note`).
</threat_model>
