<threat_model>
Threats:
- T-06-05: Scope injection / false-negative bypass: Empty scope returned by `getStagedFiles` or `getWorkingFiles` causing the engine to report 0 findings on modified files, allowing vulnerabilities to pass uninspected into production.
- T-06-06: Orphaned background child processes / unmanaged process groups: Abrupt SIGINT cancellation during static analysis or git inspection leaving lingering processes running indefinitely in the background.
- T-06-07: Signal race conditions & exit code corruption: Consecutive SIGINT signals ignored or blocked by synchronous operations, freezing the terminal and preventing developer escape, or unhandled errors producing corrupt exit codes.
Mitigations:
- T-06-05 Mitigation: `getStagedFiles` and `getWorkingFiles` in `src/repository/scope.ts` are wired to `git.statusMatrix` with strict matrix comparison rules (evaluating stage vs head and workdir vs stage), accurately reflecting modified, added, and deleted files in the review scope.
- T-06-06 Mitigation: Cancellation flows through `withCancellation` and `AbortController`. The command attaches to `controller.signal` which triggers `killProcessTree` to terminate entire child process trees and aborts in-flight network requests.
- T-06-07 Mitigation: A double-Ctrl+C trap (`sigintCount >= 2`) immediately calls `process.exit(130)` unconditionally, guaranteeing an instant escape hatch regardless of asynchronous promise state, and deterministic exit code mapping handles all failure and blocking modes.
</threat_model>
