<threat_model>
Threats:
- T-06-01: Threshold bypass / false passes: Flawed severity comparison (e.g. string comparison instead of numeric weight) or incorrect boundary checks leading to unblocked critical security findings in CI.
- T-06-02: Stream pollution: Progress events or debug messages leaking into stdout during `--json` or `--sarif` runs, corrupting machine-readable outputs and breaking downstream CI pipelines.
Mitigations:
- T-06-01 Mitigation: `SEVERITY_LEVELS` maps each severity to an explicit integer rank (`critical: 5`, `high: 4`, `medium: 3`, `low: 2`, `info: 1`). Comparison `findingLevel >= thresholdLevel` guarantees deterministic evaluation. Advisory thresholds (`none`, `off`) explicitly return `false` without evaluating finding levels.
- T-06-02 Mitigation: `StderrProgressReporter` strictly writes to `options.stream ?? process.stderr`. When `quiet`, `json`, or `sarif` is true, `this.enabled` is set to `false`, guaranteeing complete silence.
</threat_model>

         - `private readonly enabled: boolean`: initialized to `!options.quiet && !options.json && !options.sarif`.

         - `private readonly isTTY: boolean`: reads `Boolean((this.stream as { isTTY?: boolean | undefined }).isTTY)`.
       - Method `report: ReviewProgressCallback`:
         - Returns immediately if `!this.enabled`.
         - Formats prefix: `pc.dim('[${event.step.current}/${event.step.total}] ')` if `event.step` present.
