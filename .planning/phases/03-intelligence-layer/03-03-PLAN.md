<threat_model>
Threats:
- Huge repository diffs or gigantic source files causing memory exhaustion (OutOfMemory) during context aggregation
- Token budget overflow causing downstream AI provider request rejection (400 Bad Request / context_length_exceeded)
Mitigations:
- Token budgeting enforces hard token ceilings (default 12,000 tokens, configurable 8,000–16,000)
- Character heuristic includes a 10% conservative safety margin
- Oversized snippets are truncated and windowed before inclusion
- Large diffs are prioritized at the file level and summarized when exceeding capacity
</threat_model>

Implement the Context Engine, token budgeting manager, candidate scoring, and call-site snippet windowing.

Purpose: Downstream AI reviewers require high-signal, relevant code context without exceeding model token limits (8k–16k tokens) or blowing latency budgets.
Output: Tested `ContextEngine`, `TokenBudgetManager`, `CandidateCollector`, and `windowSnippet` utilities.
</objective>
