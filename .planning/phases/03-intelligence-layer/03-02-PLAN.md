<threat_model>
Threats:
- Corrupted or tampered `graph.json` in cache causing crashes or poisoning symbol resolution
- Denial of Service through cyclic graph traversal or unbounded memory consumption on large repositories
Mitigations:
- Validate loaded `graph.json` structure on deserialize; if parsing fails, discard cache and recompute graph
- Enforce strict 1-hop traversal (no unbounded recursive walks)
- Enforce caller fan-in limits (max 10 callers per symbol)
</threat_model>

Purpose: Downstream context selection relies on deterministic graphs linking changed files and symbols to their callers, tests, interfaces, and dependencies.

</objective>

<action>
Implement `src/intelligence/graph/reference.ts`:
1. `ReferenceGraph` class:
   - Maintains adjacency lists:
     - `outgoing: Map<string, GraphEdge[]>`
     - `incoming: Map<string, GraphEdge[]>`
     - `nodes: Map<string, GraphNode>`
   - `addEdge(edge: GraphEdge)`: inserts edge and reciprocal edge (e.g. `calls` creates `called_by` in reverse)
   - `getCallers(symbolId: string, limit = 10): GraphEdge[]` (D-01, D-02):
     - Returns direct 1-hop callers
     - Proximity sorting: callers in same directory first, then same package, then tests
     - Caps result to `limit` (default 10)
   - `getCallees(symbolId: string): GraphEdge[]`: returns direct 1-hop callees
   - `getImplementations(interfaceSymbolId: string): GraphEdge[]` (D-12)
   - `getTestsForFile(filePath: string): string[]` (D-10): returns test file paths associated with `filePath`
   - `getLayer(filePath: string): string | undefined` (D-11): returns architectural layer tag (`route`, `service`, `repository`, `controller`, etc.) based on directory/file pattern or custom config
2. `createReferenceGraph(files: ParsedFile[], symbolIndex: SymbolIndex, pathResolver: PathResolver, layerConfig?: Record<string, string>): ReferenceGraph`:
   - Builds import edges (`importer -> imported`)
   - Resolves call sites via lexical import matching (`import { x } from './y'` -> call to `x` in caller connects to `y:x`) (D-09)
   - Connects `implements` / `extends` edges from `symbolIndex`
   - Connects multi-signal test-production edges:
     - Name matching: `foo.ts` <-> `foo.test.ts`, `tests/test_foo.py` <-> `foo.py`
     - Import matching: test file imports production file
   - Tags architectural layers on nodes
</action>
