<threat_model>
Threats:
- Exposure of `NVIDIA_API_KEY` in logs, exception stack traces, or console output.
- Denial of Service / API quota exhaustion via unbounded concurrent requests.
- Hanging CLI processes caused by unresponsive external API sockets.
Mitigations:
- Pino logger auto-redacts `NVIDIA_API_KEY` and `Authorization` headers; error handlers strip auth headers from serialized error context.
- `PromisePool(2)` bounds concurrent outbound requests.
- 60s timeout enforced via `AbortSignal.any([timeoutSignal, userSignal])` ensures sockets are forcefully terminated.
</threat_model>
