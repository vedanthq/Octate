<threat_model>
Threats:
- T-08-05: Model provider outage, offline network, or missing linters causing unhandled crashes in diagnostic tools. If network is down or user is offline, `octate doctor` must not crash with uncaught fetch errors; it must gracefully report `status: 'warn'` or `status: 'fail'` with actionable messages.
- T-08-06: Uncaught asynchronous rejections or exceptions leaking stack traces to stdout and freezing terminals. Process errors must be intercepted by global handlers and formatted to stderr with deterministic exit code 5.

Mitigations:
- T-08-05 Mitigation: `checkNvidiaConnectivity` wraps HTTP requests in `try/catch` with a 10s timeout AbortController. Network errors, timeouts, and missing keys map to typed warning/fail results without throwing.
- T-08-06 Mitigation: `src/cli.ts` installs `process.on('uncaughtException')` and `process.on('unhandledRejection')` that write formatted errors to stderr and exit with code 5.
</threat_model>

       ```typescript
         logger.fatal({ error: error.message, stack: error.stack }, 'Uncaught exception');
         process.stderr.write(`\nFatal Error: ${error.message}\n`);
         process.exit(5);
       });

       process.on('unhandledRejection', (reason: unknown) => {
         const message = reason instanceof Error ? reason.message : String(reason);
         logger.fatal({ reason }, 'Unhandled rejection');
         process.stderr.write(`\nFatal Error: ${message}\n`);
         process.exit(5);
       });
       ```
