- T-08-04: False-positive flood or missed critical bugs eroding developer trust. Review findings must be verified against ground truth to guarantee precision > 70% and false-positive rate < 30%.
- T-08-07: Flaky CI runs caused by non-deterministic network model requests during evaluation. Evaluation tests must be 100% deterministic in offline CI while allowing live validation when requested.

Mitigations:
- T-08-04 Mitigation: Negative-case pairing (Clean vs Vulnerable) tests both bug detection (True Positives) and benign rejection (False Positive suppression via Critic hard floor + LLM Critic).

</threat_model>
