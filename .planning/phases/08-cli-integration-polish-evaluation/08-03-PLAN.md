<threat_model>
Threats:
- T-08-01: Development secrets, test tokens, or scratch files leaked into published npm package. If `package.json` lacks an explicit `files` whitelist or `.npmignore`, credentials or private development files could be distributed to public registries.
- T-08-02: Missing executable permissions (`EACCES`) on `dist/cli.js` when executed via `npx octate review`. The published tarball must preserve the executable bit on the binary entrypoint.
- T-08-03: `Language.load()` failures in production installs due to hardcoded relative paths targeting `test-wasm/`. Production bundles must ship WASM grammars in `dist/wasm/` and resolve paths dynamically.

Mitigations:
- T-08-01 Mitigation: `package.json` configures strict `files: ["dist", "README.md", "LICENSE"]`. `npm run pack:check` runs `npm pack --dry-run` to assert tarball size and file contents.
- T-08-02 Mitigation: Build script executes `chmod +x dist/cli.js` and includes `#!/usr/bin/env node` shebang.
- T-08-03 Mitigation: `src/analysis/parser/index.ts` introduces `resolveWasmPath()` checking `dist/wasm/` first, and `scripts/copy-wasm.cjs` copies WASM files on every build.
</threat_model>
